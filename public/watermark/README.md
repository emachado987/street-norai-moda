# AI CREATED — versión calada tipográfica

## Composición

- Únicamente texto; sin placa, fondo, círculos, contornos ni símbolos.
- `AI` como elemento dominante.
- `CREATED` condensado debajo y con ancho óptico equivalente.
- `ORIGEN·DIGITAL` distribuido alrededor en secuencia circular y con giro tangencial.

## Colores

- Gris oscuro: `#343739`, para fondos claros.
- Gris claro: `#D8D9D5`, para fondos oscuros.

## Archivos

- `ai-created-cutout-dark-grey.png` / `.svg` — gris oscuro sobre transparencia.
- `ai-created-cutout-light-grey.png` / `.svg` — gris claro sobre transparencia.
- `ai-created-cutout-preview.jpg` — comparación y aplicación a escala real.

## Aplicación

- Escala recomendada: 6–9 % del ancho del contenido.
- Margen de seguridad: 4 %.
- Elegir el color según el contraste local del fondo.
- Al no existir placa de contraste, debe colocarse sobre una zona visualmente uniforme.
